# Library Management System

Academic project developed in Delphi 7.

## Features

- Book registration
- Student registration
- Add and delete records
- Field validation
- Form inheritance

## Technologies

- Delphi 7
- Object Pascal
- ADO

## Database

The database `FAI` and its tables are created automatically when the application starts.

## How to Run

1. Open `atividadeBimestral.dpr` in Delphi 7.
2. Make sure SQL Server is running.
3. Run the project.
